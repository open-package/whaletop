# Packaging

| File | Purpose |
|---|---|
| `build-deb.sh` | Builds `dist/whaletop_<version>_all.deb` with bundled pure-Python dependencies |
| `build-apt-repo.sh` | Builds a signed apt repository from a directory of `.deb` files |

Release procedures and repository configuration are documented in
[docs/releasing.md](../docs/releasing.md) and published at
<https://open-package.github.io/whaletop/releasing/>.
