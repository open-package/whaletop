whaletop

An htop-style terminal UI for Docker. This is its apt repository.

Install on Debian / Ubuntu

curl -fsSL @REPO_URL@/whaletop.gpg | sudo tee /usr/share/keyrings/whaletop.gpg >/dev/null
echo "deb [signed-by=/usr/share/keyrings/whaletop.gpg] @REPO_URL@ stable main" \
  | sudo tee /etc/apt/sources.list.d/whaletop.list
sudo apt update && sudo apt install whaletop

Requires Python 3.10+: Ubuntu 22.04 or newer, Debian 12 or newer. Updates arrive with sudo apt upgrade.

Uninstall

sudo apt remove whaletop
sudo rm /etc/apt/sources.list.d/whaletop.list /usr/share/keyrings/whaletop.gpg
